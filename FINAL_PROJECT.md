# Итоговый проект — аналитика интернет-магазина ActiveShop

## Бизнес-кейс

Вы работаете аналитиком в интернет-магазине спортивных товаров **ActiveShop**.

Руководство готовит план развития на следующий год и хочет получить единый аналитический проект, который объединит навыки SQL, Python, Pandas, визуализации, статистики и BI.

Вам переданы сырые выгрузки из CRM, интернет-магазина и системы веб-аналитики. В данных специально оставлены пропуски, дубликаты и несколько аномалий. Ваша задача — подготовить данные, загрузить их в PostgreSQL, провести анализ и собрать понятный аналитический сервис.

Проект должен быть комплексным, но не требуется строить сложные ML-модели или использовать продвинутую математику.

---

## Исходные файлы

В папке `data/` находятся 5 CSV-файлов:

1. `customers.csv` — клиенты.
2. `products.csv` — каталог товаров.
3. `sessions.csv` — посещения сайта и результаты A/B-теста.
4. `orders.csv` — заказы.
5. `order_items.csv` — товары внутри заказов.

### Важные бизнес-правила

- `delivered` — успешно завершённый заказ.
- `cancelled` — отменённый заказ, в выручку не включается.
- `returned` — возвращённый заказ, в фактическую выручку не включается.
- `order_amount` — сумма заказа после скидки.
- `gross_amount` — сумма до скидки.
- Для отменённых заказов отсутствие `delivery_days` и `customer_rating` является нормальным.
- В `sessions.csv` пустой `order_id` при `converted = 0` является нормальным.
- A/B-группа закреплена за клиентом. Для статистического теста используйте **первую сессию каждого клиента**, чтобы один клиент не попадал в анализ несколько раз.

## Обязательные SQL-задачи

### 1. Основные показатели бизнеса

Рассчитайте:

- количество успешных заказов;
- общую выручку;
- средний чек;
- медианный чек — можно рассчитать в SQL или Python;
- количество уникальных покупателей.

### 2. Динамика продаж

По месяцам рассчитайте:

- выручку;
- количество заказов;
- средний чек;
- изменение выручки к предыдущему месяцу.

Для изменения к предыдущему месяцу используйте оконную функцию `LAG()`.

### 3. Категории и товары

Определите:

- категории-лидеры по выручке;
- категории-лидеры по валовой прибыли;
- топ-5 товаров по выручке;
- топ-5 товаров по количеству проданных единиц.

Валовую прибыль считайте как:

`net_revenue - unit_cost * quantity`

где скидку заказа необходимо учитывать при расчёте `net_revenue`.

### 4. Рейтинг товаров внутри категории

Для каждой категории определите топ-3 товара по выручке.

Используйте `RANK()`, `DENSE_RANK()` или `ROW_NUMBER()`.

### 5. Клиенты

Найдите:

- топ-10 клиентов по выручке;
- клиентов с наибольшим количеством успешных заказов;
- долю клиентов, совершивших больше одного успешного заказа.

### 6. Маркетинговые каналы

По данным `sessions` определите:

- количество сессий по каналам;
- конверсию в заказ;
- количество заказов;
- выручку, которую принёс каждый канал.

### 7. Скидки

Сравните:

- средний чек без промокода;
- средний чек с промокодом;
- количество заказов;
- выручку.

Не делайте причинный вывод только по этой таблице: наличие связи ещё не означает, что скидка вызвала рост продаж.

### 8. Создайте аналитическое представление

Создайте минимум одно `VIEW`, которое будет удобно использовать из Python или Superset.

Например:

`v_order_analytics`

Одна строка в представлении может соответствовать успешному заказу и содержать клиента, регион, канал, сумму заказа и основные показатели заказа.

# Этап 4. Статистика и A/B-тест

В таблице `sessions` находится результат эксперимента с двумя вариантами оформления страницы заказа:

- группа `A` — старая версия;
- группа `B` — новая версия.

Для анализа используйте **только первую сессию каждого клиента**.

Проверьте, различается ли конверсия между группами.

Необходимо:

1. Сформулировать `H0` и `H1`.
2. Рассчитать конверсию для A и B.
3. Выбрать подходящий статистический тест для двух долей.
4. Рассчитать `p-value`.
5. Построить или рассчитать 95% доверительный интервал для разницы конверсий.
6. Сделать бизнес-вывод.

Не ограничивайтесь фразой «p-value меньше 0.05». Объясните, насколько велика разница и имеет ли она практический смысл.
