# Аналитика интернет-магазина ActiveShop (Итоговый проект)

## Цель проекта
Комплексный анализ показателей интернет-магазина ActiveShop: подготовка и очистка данных, загрузка в PostgreSQL, SQL-анализ, статистика и A/B-тестирование, построение графиков, создание дашборда в Apache Superset и интерактивного веб-приложения на Streamlit.

## Исходные данные
В проекте используются 5 основных датасетов:
- `customers.csv`: Данные о клиентах (регистрация, демография, A/B-группы).
- `products.csv`: Каталог товаров (категории, бренды, себестоимость, базовые цены).
- `sessions.csv`: Веб-сессии пользователей и результаты A/B-теста.
- `orders.csv`: Информация о заказах (статусы, способы оплаты, промокоды, суммы).
- `order_items.csv`: Состав заказов (товары, количества, цены).

## Этап 4. - Статистический анализ и A/B-тестирование
-----------------------------------------------------------------------------------------------

### Этап 4. Статистический анализ и A/B-тестирование

#### 1. Гипотезы и методология
* **Формулировка гипотез:**
  * **Нулевая гипотеза (H_0):** Новый вариант оформления checkout-страницы (Группа B) не влияет на конверсию пользователей при первом визите (CR_A = CR_B).
  * **Альтернативная гипотеза (H_1):** Конверсия при первом визите статистически значимо различается между версиями (CR_A - CR_B).
* **Фильтрация данных:** Отбракованы повторные визиты, оставлены строго **первые сессии 1 997 уникальных клиентов** (`customer_id`) для сохранения независимости наблюдений.
* **Статистический критерий:** Двухвыборочный Z-тест для независимых долей (Two-Sample Z-Test for Proportions) при α = 0.05.

#### 2. Результаты эксперимента

| Показатель / Группа | Группа A (Control) | Группа B (Treatment) | Разница / Эффект |
| :--- | :---: | :---: | :---: |
| **Уникальные пользователи (1-я сессия)** | 999 | 998 | — |
| **Количество конверсий** | 290 | 375 | — |
| **Коэффициент конверсии (CR)** | **29.03%** | **37.58%** | **+8.55 p.p.** |
| **Относительный прирост (Lift)** | — | — | **+29.44%** |
| **Z-статистика / p-value** | — | — | **Z = 4.0518, p = 0.000051** |
| **95% Доверительный интервал** | — | — | **[+4.41%, +12.68%]** |

#### 3. Бизнес-вывод и практическая значимость
1. **Статистическая значимость:** p-value = 0.000051 < 0.05. Нулевая гипотеза отвергается. Различие в конверсиях является статистически достоверным и не связано со случайными колебаниями выборки.
2. **Практическая значимость (Business Impact):** Новый вариант интерфейса увеличивает конверсию первого визита с **29.03% до 37.58%** (абсолютный прирост **+8.55 процентных пункта**, относительный рос **+29.44%**). С вероятностью 95% минимальный гарантированный прирост конверсии составляет **+4.41 p.p.**
3. **Бизнес-рекомендация:** Раскатать новый вариант оформления заказа (Группа B) на 100% пользователей.

6. **Результаты A/B-тестирования (Первая сессия):** Визуализирует статистически значимый рост конверсии первого визита с **29.03%** (Группа A) до **37.58%** (Группа B), что дает абсолютный прирост **+8.55 процентных пункта**.

#### Дополнительный анализ (сетка 1x2):
* **Распределение чека заказов:** Распределение сумм заказов имеет выраженную правостороннюю асимметрию с медианным чеком **$315.13** и средним значением **$388.37** (хвост распределения уходит выше $1,500 за счет крупных покупок).
* **Структура способов оплаты:** Абсолютным лидером по объему выручки является оплата банковскими картами (**Card — 56.6%**), за которой следуют **PayPal** (**18.5%**), **Apple Pay** (**13.9%**) и наличные (**Cash — 10.6%**).

### Бизнес-выводы и рекомендации (Итоги Этапа 5)
